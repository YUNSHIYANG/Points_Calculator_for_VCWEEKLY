欢迎使用周刊得点计算器！  
本计算器根据中V周刊组当前公式整理，由云师阳(B站UID:1866643210)制作。 
  
**v1.1使用说明**  
通过文件[周刊得点计算模板.xlsx]填写数据即可显示得点，文件内的图片是DeepSeek-V4-Pro对视频数据各维度的分析。  
您也可以使用可执行文件[周刊得点自动获取脚本1.1.exe]直接调用API获取当前数据并直接得到分数。  

**v2.1使用说明**  
请同时下载文件[bvid.xlsx]和可执行文件[周刊得点自动获取脚本2.1.exe]，并将前者的文件名修改为您希望查询视频的BV号。  
请您在Excel表格内手动填写区准确填写往期截止数据，这样您就可以实现对每周增量及分数的统计计算了。  
如果出现增量未被减去的情况，请重新填写表格数据以刷新缓存。  

**v2.2使用说明**  
修复了表格写入缓存清空导致往期数据无法正确加载的bug，脚本将自动执行加和操作。  

**值得说明的是**，可执行文件请您访问release进行下载！  
名字形如PCVCW_v1.1.exe的就是可执行文件了，切记v2系列需要结合[bvid.xlsx]这一Excel表格使用。
